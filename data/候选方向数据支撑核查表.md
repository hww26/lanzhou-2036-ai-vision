## 二、三个推荐方向的独立一手数据流核查

### 方向1：算力与数字经济 ✅
| 检查项 | 依据 |
|---|---|
| 实物载体 | 新区大数据产业园：建成2.3万机架、85万核、72PB，在建5.6万机架，入选国家新型工业化示范基地 |
| 增长驱动力 | 信息传输软件业增加值+15.2%；数字经济规模1001亿(2024,+7.9%)；全国数字百强第55 |
| 政策抓手 | "东数西算"国家枢纽(甘肃)核心；国家级互联网骨干直联点(网间时延降83.7%) |
| 一手数据流 | 机架/电表/电价/在用核数/业务流水（采集）→ 清洗归一（处理）→ 需求预测与选址优化（分析）→ 招商清单与机柜分配（决策） |
| AI技术 | 算力调度（错峰）/ 大模型推理成本预测 / 能耗-算力联合优化 |

### 方向2：银发经济与智慧养老 ✅
  | 检查项 | 依据 |
  |---|---|
  | 人口基础 | 60+ 103.8万(23.32%)，65+ 74.91万(16.83%)；各区县人口结构数据可获得 |
  | 承接载体 | 793个社区养老设施、23家机构(医养结合100%)、132个幸福食堂(月供35万人次) |
  | 一手数据流 | 医院心电图/慢病档案/养老床位数/助餐人次（采集）→ 健康画像与风险分层（处理分析）→ 慢病预测与照护资源调配（决策） |
  | AI技术 | 时序健康预测、风险分层、需求预测、多模态病历理解 |

### 方向3：文旅与黄河夜游 ✅
  | 检查项 | 依据 |
  |---|---|
  | 游客规模 | 境内1.29亿人次(+17.29%)、收入1000.12亿(+22.48%)、入境+54.48%、人均花费775.36元 |
  | 热点载体 | 中山桥/黄河楼/兰州老街/金城关/水墨丹霞；轨道1/2号线并网串联 |
  | 一手数据流 | 票务/闸机/视频/社交打卡+评论（采集）→ 情感与热度分析（处理）→ 客流预测与服务调度（分析决策） |
  | AI技术 | 客流时序预测、评论情感分析、视频质量 |

## 三、其余候选方向核查结论（供左栏"为何不选"）

| 方向 | 结论 | 理由 |
|---|---|---|
| 通道经济/物流 | 旁证可用 | 有国际班列/外贸数据，但"通道经济"难以落到普通市民的一天，且数据偏部门报表 |
| 黄河大生态治理 | 可用但属维持型 | 水质已100%达标，AI增量主要在监测预警，非增长主线 |
| 轨道与低空 | 支撑型 | 更适合作为文旅/交通的一个载体，不单独成方向 |
| 都市农业/中药材 | 数据可得性中 | 农业数字化在兰州数据可得性最弱，且与"一天"场景关联弱 |
| 智慧政务 | 数据强牵涉 | 政务数据敏感，难公开核验，推荐分低 |

---

**结论：1、2、3 三个方向（算力/银发/文旅+夜游）均有独立一手数据流 + 实物载体 + 政策依据，作为推荐三方向通过核查。**
